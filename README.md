# PWDStorage
Учебное Android-приложение на Java для хранения паролей. Сохранились исходники, ресурсы, тестовые заготовки и Gradle Wrapper.
Откройте проект в Android Studio. Для сборки нужны JDK 17 и Android SDK 33. Собрать отладочный APK можно командой 'gradlew.bat assembleDebug' в Windows или './gradlew assembleDebug' в Linux.
